# まどりくん

スキャンPDFや画像をなぞって、不動産の募集図面に使う間取り図を作るPCブラウザ向けのエディターです。

## 起動

Node.js 22.13 以降で実行します。

```sh
npm ci
npm run dev
```

本番用ファイルは `npm run build` で `dist/` に生成されます。

## 使い方

1. キャンバスにPDF・PNG・JPEG・WebPをドロップします。下絵の位置、倍率、回転、不透明度を右欄で調整できます。PDFの場合はページも選べます。
2. 「床」でフローリングか畳の模様を描き、「色」で洋室・和室・水回りなどの色を塗ります。壁を描き、窓・扉・設備をパレットからドラッグして配置します。レイヤー右端で表示とロックを切り替えます。
3. 「保存」で制作ファイルをダウンロードします。`.madori` を開くと、同梱の下絵と図形を復元できます。
4. 「書き出し」でJPEG・PNG・PDF・SVGと、カラーまたは白黒を選びます。下絵を含めるかは書き出し時に指定できます。

キーボード操作は画面右下のヘルプで確認できます。
